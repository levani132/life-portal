# Historical Shortcut artifacts

The original `.plist`, `.shortcut`, and `build-health-shortcut.py` files here are retained
as historical references. They implement a retired date-window protocol and are not the
current installation source. Do not regenerate or publish them for recent-sample sync.

Follow `docs/integrations/apple-health-shortcut-manual.md` to edit and share the current
single-upload iPhone Shortcut. Existing user-created files are preserved.
